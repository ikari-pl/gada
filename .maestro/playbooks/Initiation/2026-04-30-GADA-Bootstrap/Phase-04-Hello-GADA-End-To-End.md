# Phase 04: hello, GADA — First End-to-End Transpilation

This is the headline phase of the bootstrap. By the end of it, a Go file `examples/hello/hello.go` containing nothing more than `package main; import "fmt"; func main() { fmt.Println("hello, GADA") }` is transpiled to Ada by the GADA compiler, compiled by `gprbuild`, and runs to print `hello, GADA`. This is the first time the entire pipeline (Go AST → GADA-IR → Ada source → GNAT → native binary linked against `Gada.Core.IO`) executes end-to-end. Once this phase is `DONE`, the project's central thesis — *Go programs run on the GCC Ada toolchain* — is empirically demonstrated, even if only on one trivial program. Every later phase widens that pinhole.
