## ADRs landed

- **[[ADR-0001]] (Go AST frontend)** — front-end is upstream `go/ast`
  + `go/types` + `golang.org/x/tools/go/packages`; we will never write
  a Go parser, type checker, or module resolver.
- **[[ADR-0002]] (Layered runtime)** — four-layer stack `Gada.Core`
  < `Gada.Async` = `Gada.Reflect` < `Gada.Std` with no upward `with`
  and no `Async`↔`Reflect` sibling `with`.
- **[[ADR-0003]] (Boehm GC for v1)** — Boehm-Demers-Weiser is v1 GC;
  conservative scanning lets goroutine stacks be traced without
  per-frame stack maps; precise GC is post-1.0 + a follow-on ADR.
- **[[ADR-0004]] (libco scheduler + Ravenscar)** — hosted M:N over
  Ada tasks + libco for goroutine context switches; Ravenscar mode
  runs one Ada task per goroutine with bounded count for certifiable
  scheduling.

Cross-link graph: 0001 ↔ 0002, 0002 → 0003, 0002 → 0004, 0003 ↔ 0004.
