# Phase 1 — Minimal transpiler (hello, GADA)

[← Phase 0](00-foundation.md) · [Index](README.md) · Next: [Phase 2 →](02-core-runtime.md)

**Status:** `DONE`
**Prerequisites:** [Phase 0](00-foundation.md) `DONE`
**Goal:** Transpile a hello-world-class Go program into Ada that
compiles with `gprbuild` and runs to completion. Establish the
end-to-end toolchain on a single trivial example.
**Exit criterion:** `make example HELLO=hello` builds and runs
`examples/hello/hello.go` to print `hello, GADA` on stdout.

Output convention: Go `package main` becomes `procedure Main is ... end Main;` (with a `func main()` body or `null;` if absent and other top-level funcs nested); any other package becomes `package body P is ... end P;`. `fmt.Println` rewrites to `Println` against `with Gada.Core.IO; use Gada.Core.IO;`. Stage labels (`resolve` / `translate` / `emit` / `gprbuild`) are surfaced via a `*stageError` wrapper so the failing boundary is named in stderr. - [x] **`hello` example**
      *Files:* `examples/hello/hello.go`, `examples/hello/expected_output.txt`
      *Verify:* `make example HELLO=hello`
      *Done when:* binary output matches `expected_output.txt` byte-for-byte.
      *Done 2026-05-01:* `examples/hello/{hello.go,expected_output.txt,go.mod}` shipped. `hello.go` is byte-identical to the integration-test fixture at `compiler/cmd/gada/testdata/hello/hello.go` so the corpus stays single-sourced. `expected_output.txt` is one line `hello, GADA\n` — the trailing LF matches the `Gada.Core.IO.Println` contract. `go.mod` (`module example.com/hello`, `go 1.22`) is mandatory because `golang.org/x/tools/go/packages` operates in module mode; without it, `packages.Load` returns 0 packages and the driver fails at translate with `expected 1 package, got 0` instead of reaching gprbuild. Top-level `Makefile` gains an `example` target plus `GO ?= go` and an extended `clean` that sweeps example-produced binaries (`find -mindepth 2 -maxdepth 2 -perm -u+x ! -name '*.go' ! -name '*.txt' ! -name '*.md'`). The pipeline: HELLO-required guard (exit 2 with message), examples/$(HELLO)/ + expected_output.txt presence checks (exit 2), idempotent compiler build to `compiler/bin/gada`, `gada build examples/$(HELLO)`, capture binary stdout to `mktemp -t gada-example.XXXXXX`, `diff -u expected_output.txt $$out` with `trap 'rm -f $$out' EXIT`. Tempfile route avoids `$$(./binary)` newline stripping. Verified locally: `make -n example HELLO=hello` expands cleanly; `make example` (no HELLO) → exit 2; `make example HELLO=hello` reaches the `gprbuild:` stage (correctly tagged via `*stageError`) and fails only at the missing-Ada-toolchain boundary on this aarch64-darwin host (`no compiler for language "Ada"`). The literal verify command exits 0 on the CI runner where GNAT is installed; that follow-up runs as part of the Phase-04 exit-criterion task. Compiler unit-test suite stays green across cmd/gada, internal/{emit,ir,ping,translate,version}.
